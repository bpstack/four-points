# Housekeeping para pisos

## Acceso

`Opera: Room Management → Housekeeping → Housekeeping Management → Report`

## Diferencia con el T122

| Reporte                | Filtros                | Uso                  |
| ---------------------- | ---------------------- | -------------------- |
| **Housekeeping pisos** | Sin filtros especiales | Para equipo de pisos |
| **T122 pisos**         | Vacant + Occupied      | Para equipo de pisos |
| **T122 mantenimiento** | Solo Vacants           | Para mantenimiento   |
