# D114 — Revenue detallado

## Acceso

`Miscellaneous → Reports → D114`

## Uso

- Sacar el D114 del **día anterior**
- Usar para rellenar el Excel de **Daily Revenue F&B**
- El total del Excel debe coincidir con **Food and Beverage Revenue** del Manager Flash
