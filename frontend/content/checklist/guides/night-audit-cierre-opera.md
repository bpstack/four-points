# End of Date / Night Audit en Opera

## Cuándo ejecutar

A partir de las **00:00**, una vez completado el pre-cierre:

- Caja cerrada
- Exchange rate introducido

---

## Pasos

**Ruta: System → End of Day**

1. Seguir el asistente: **next → next → next** hasta completar
2. Esperar a que el sistema procese

---

## Consecuencias del cierre

| Efecto            | Descripción                                                                  |
| ----------------- | ---------------------------------------------------------------------------- |
| **No Show**       | Todas las reservas que no hayan realizado check-in se marcan automáticamente |
| **Cambio de día** | El sistema pasa al día siguiente                                             |
| **Reportes**      | Se generan los reportes del día que acaba                                    |

---

## Si falla

> ⚠️ **No reintentar** sin contactar IT primero.

- Documentar el error exacto que aparece en pantalla
- Contactar IT antes de reintentar

---

## Notas

- El cierre puede variar de hora según la carga de trabajo del turno
- Es importante que la caja esté cerrada y el exchange rate introducido antes de ejecutar
