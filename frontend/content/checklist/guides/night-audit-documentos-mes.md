# Documentos último día de mes

## Para GM

### Financial Transaction Summary

- Mes actual
- **Group By:** Transaction Code

## Para auditor externo

Guardar en su carpeta y enviar por email:

- **Deposit Ledger**
- **Manager Flash**
- **Reservation Statistics**

## Para Dirección y auditoría (AUD, GD1 y GD2)

- Ir a `Miscellaneous → Reports → Manager Flash`
- Marcar **Month** y seleccionar el mes que acaba de finalizar
- Generar **2 documentos**:
  1. Con **TAX** marcado
  2. Sin TAX
